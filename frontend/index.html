SPI and SPEI indices

SPI and SPEI are standardized indices used to monitor meteorological drought.

SPI: calculated from precipitation.

SPEI: includes precipitation plus temperature and potential evapotranspiration effects.

Both are useful for short-term and seasonal drought analysis across regions.

SPI method: computed with the Standardized Drought Analysis Toolbox (SDAT) framework.

Data summary

Source: synoptic weather stations in Iran

Time coverage: from station inception through 2025

Variables: monthly precipitation (and monthly temperature for SPEI)

Indices are computed independently for each station using its full historical record.
References

Inspired by drought.eng.uci.edu.

Hao Z., AghaKouchak A., Nakhjiri N., Farahmand A. (2014). Global Integrated Drought Monitoring and Prediction System. Scientific Data, 1:140001. doi:10.1038/sdata.2014.1

Farahmand A., AghaKouchak A. (2015). A Generalized Framework for Deriving Nonparametric Standardized Drought Indicators. Advances in Water Resources, 76, 140-145. doi:10.1016/j.advwatres.2014.11.012

What is SPI-3 / SPEI-3?
  • Uses a rolling 3-month aggregation window.
  • Sensitive to short-term and seasonal variability.
  • Useful for agricultural drought, soil moisture deficits, and short-term water stress.
Drought severity classes

SPI ≥ -0.5: Normal/Wet conditions

-0.8 < SPI < -0.5: D0 - Abnormally Dry

-1.3 < SPI ≤ -0.8: D1 - Moderate Drought

-1.6 < SPI ≤ -1.3: D2 - Severe Drought

-2.0 < SPI ≤ -1.6: D3 - Extreme Drought

SPI ≤ -2.0: D4 - Exceptional Drought

Important note

SPI/SPEI values are computed from each station's full statistical period and are not recalculated based on user-selected ranges.

What is trend analysis?

Trend analysis examines how a variable changes through time and whether values are systematically increasing, decreasing, or stable.

Mann-Kendall test

The Mann-Kendall test is non-parametric and does not require a specific distribution assumption.

Trend metrics

Kendall's τ: correlation measure from -1 to +1. Positive values indicate increasing trends; negative values indicate decreasing trends.

P-value: statistical significance indicator. A value below 0.05 is typically considered significant at 95% confidence.

Sen's slope: robust estimate of median rate of change over time.

Trend line

The trend line visualizes the overall direction implied by Sen's slope.

About this dashboard

This dashboard is tailored for Iran's drought monitoring workflow. It visualizes SPI/SPEI indices for Iranian stations and management levels, and it is inspired by drought.eng.uci.edu.

  • Map: hover for quick details, click for region analysis.
  • Colors: based on drought classes (D0 to D4) and normal/wet status.
  • Performance: API requests are cached and the page updates without full reload.
  • Layout: responsive design for desktop and mobile.

SPI method: computed with the Standardized Drought Analysis Toolbox (SDAT) framework using the references listed below.

  • Hao Z., AghaKouchak A., Nakhjiri N., Farahmand A. (2014). Scientific Data, 1:140001.
  • Farahmand A., AghaKouchak A. (2015). Advances in Water Resources, 76, 140-145.
API usage (full example)

Default API base URL: http://localhost:8000

  • GET /datasets — list available layers
  • GET /meta?level=station — metadata (time range + indices)
  • GET /mapdata?level=station&index=spi3&date=2020-01 — map data
  • GET /timeseries?region_id=10001&level=station&index=spi3 — time series
  • GET /kpi?region_id=10001&level=station&index=spi3&date=2020-01 — KPI + trend

End-to-end cURL example:

# 1) Get datasets
curl "http://localhost:8000/datasets"

# 2) Get metadata for station layer
curl "http://localhost:8000/meta?level=station"

# 3) Get map data for a climate index (example: precip)
curl "http://localhost:8000/mapdata?level=station&index=precip&date=2020-01"

# 4) Get time series for one region
curl "http://localhost:8000/timeseries?region_id=10001&level=station&index=precip"

# 5) Get KPI + trend for the same region at one month
curl "http://localhost:8000/kpi?region_id=10001&level=station&index=precip&date=2020-01"
For best experience, use an up-to-date browser. On mobile, open or close panels from the header buttons.
